# Sagar's Web Café ☕🍽️

Welcome to **Sagar's Web Café** – a beautifully crafted web application that showcases a fictional café menu with an elegant design and intuitive user experience. Built with **React**, **Material UI**, and **useContext** for cart management.

---

## 🌐 Live Demo
👉 [Visit the Website](https://sagargautam0210.github.io/sagars-web-cafe/) *(Replace with your live URL)*

---

## ✨ Features
- 🏠 **Home Page** with bold, centered branding
- 📖 **About Us Page** with photo and details
- 📋 **Menu Page** displaying items with descriptions
- 🛒 **Add to Cart** functionality using `useContext`
- 🧹 **Clear Cart** and **Remove Item** options
- 📱 **Responsive Design** for all devices
- 🎨 Styled using **Material UI (MUI)** for modern UI
